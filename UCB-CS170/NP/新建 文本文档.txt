P vs NP 问题的定义
English: P is the set of decision problems solvable in polynomial time. NP is the set of decision problems for which a solution can be verified in polynomial time.
Chinese: P是可以在多项式时间内解决的决策问题集合。NP是可以在多项式时间内验证解的决策问题集合。
Summary: P是可解问题，NP是可验证问题。P ⊆ NP，P = NP问题是计算机科学中最重要的未解决问题。
多项式时间归约 (Polynomial-time Reduction)
English: A problem A can be reduced to problem B in polynomial time if there exists a polynomial time algorithm that transforms any instance of A into an instance of B such that the solution to B gives a solution to A.
Chinese: 如果存在一个多项式时间算法，将问题A的任何实例转换为问题B的实例，使得B的解可以给出A的解，则问题A可以在多项式时间内归约到问题B。
Summary: 多项式时间归约是证明NP完全性的重要工具，用于建立问题间的难度关系。
NP完全性 (NP-completeness)
English: A problem X is NP-complete if X ∈ NP and for every problem Y ∈ NP, Y can be reduced to X in polynomial time.
Chinese: 一个问题X是NP完全的，如果X ∈ NP且对于所有Y ∈ NP，Y可以在多项式时间内归约到X。
Summary: NP完全问题是NP中最难的问题，如果其中一个NP完全问题有多项式时间算法，则所有NP问题都有多项式时间算法。
SAT (Boolean Satisfiability)
English: Given a Boolean formula in conjunctive normal form (CNF), find a truth assignment that satisfies all clauses, or report that none exists.
Chinese: 给定一个合取范式(CNF)的布尔公式，找到一个满足所有子句的真值赋值，或者报告不存在这样的赋值。
Summary: SAT是第一个被证明为NP完全的问题，是NP完全性理论的基石。SAT的特殊案例3SAT也是NP完全的。
TSP (Traveling Salesman Problem)
English: Given a complete graph with edge weights, find a cycle that visits each vertex exactly once with minimum total weight.
Chinese: 给定一个带权完全图，找到一个访问每个顶点恰好一次的环，使得总权重最小。
Summary: TSP是NP完全的，是组合优化问题的典型代表。在满足三角不等式的条件下，存在2-近似算法。
Vertex Cover
English: Given a graph and an integer k, find a set of k vertices such that every edge is incident to at least one vertex in the set.
Chinese: 给定一个图和整数k，找到k个顶点的集合，使得每条边至少有一个端点在该集合中。
Summary: 顶点覆盖问题是NP完全的，但存在2-近似算法。与独立集问题密切相关，顶点覆盖的补集是独立集。
Independent Set
English: Given a graph and an integer k, find a set of k vertices such that no two are adjacent.
Chinese: 给定一个图和整数k，找到k个顶点的集合，使得其中任意两个顶点都不相邻。
Summary: 独立集问题是NP完全的，是图论中的基本问题。在树结构上，可以在多项式时间内解决。
Clique
English: Given a graph and an integer k, find a set of k vertices such that every pair of vertices in the set is adjacent.
Chinese: 给定一个图和整数k，找到k个顶点的集合，使得集合中每对顶点都相邻。
Summary: 团问题是NP完全的，是图论中的基本问题。与独立集问题相关，团问题的补图是独立集问题。
Backtracking
English: A search algorithm that incrementally builds candidates to the solution and abandons a candidate as soon as it determines that the candidate cannot possibly be completed to a valid solution.
Chinese: 一种搜索算法，通过逐步构建解的候选，一旦确定候选不能完成为有效解，就放弃该候选。
Summary: 回溯法是一种智能穷举搜索策略，通过尽早排除不可能的路径来提高搜索效率。在SAT问题中，对小规模问题特别有效。
Branch-and-bound
English: A method for solving optimization problems that combines the idea of branch and bound, where the search space is divided into subproblems and bounds on the optimal solution are used to prune the search tree.
Chinese: 一种解决优化问题的方法，结合了分支和界限的思想，将搜索空间划分为子问题，并使用最优解的界限来修剪搜索树。
Summary: 分支定界法是智能穷举搜索的扩展，用于优化问题，通过界限来减少搜索空间。在TSP问题中，使用最小生成树作为下界。
Approximation Algorithm
English: An algorithm that finds a solution to an optimization problem that is within a guaranteed factor of the optimal solution.
Chinese: 一种为优化问题找到解的算法，该解在保证的因子内接近最优解。
Summary: 近似算法是应对NP完全优化问题的主要策略，提供了解的近似质量保证。顶点覆盖问题的2-近似和背包问题的(1-ε)-近似是典型例子。
Local Search Heuristics
English: A heuristic method that starts with an initial solution and iteratively moves to a neighboring solution with better cost until a local optimum is reached.
Chinese: 一种启发式方法，从初始解开始，迭代地移动到成本更好的邻近解，直到达到局部最优。
Summary: 局部搜索启发式是应对NP完全问题的实用策略，通过局部改进寻找高质量解。2-change局部搜索和模拟退火是常用方法。
P vs NP问题的意义
English: The P vs NP problem is one of the most important open questions in computer science, with implications for cryptography, optimization, and many other fields.
Chinese: P vs NP问题是计算机科学中最重要的未解决问题之一，对密码学、优化和其他许多领域有深远影响。
Summary: P vs NP问题的解决将彻底改变我们对计算复杂性的理解，可能带来革命性的算法和应用。其解决将意味着所有NP问题都有多项式时间算法。
